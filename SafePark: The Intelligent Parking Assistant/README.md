||SafePark:The Intelligent Parking Assistant||

SafePark:The Intelligent Parking Assistant is an IoT-based safety system using ESP32 and an HC-SR04 ultrasonic sensor to detect vehicle-to-obstacle distances in real time, providing immediate visual and audio safety alerts via a Red LED and Buzzer.

🎯 Key Features:
Real-Time Distance Monitoring: Dynamically measures the distance between the vehicle and obstacle.

📍 Where It's Used:
Automobile Parking Assistance: Prevents collisions during reverse or parallel parking.
Garage Safety Systems: Guides drivers to park safely inside tight spaces.
Robotics & Automation: Collision prevention for autonomous obstacle-avoiding robots.
