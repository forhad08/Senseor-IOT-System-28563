||Temperature & Humidity Monitoring System||

A simple IoT-based system that reads room temperature and humidity in real-time and triggers a warning light if it gets too hot.

🎯 Key Features: Measures temperature and humidity dynamically using a DHT22 sensor. Displays live data on the serial monitor and controls an alert LED when it crosses the safety limit. Helps automate basic climate control or room safety.

📍 Where It's Used: Smart Greenhouses: Keeping an eye on plant growth conditions. Server Rooms: Triggering warning lights to prevent hardware overheating. Home Automation: Basic room temperature and climate contro.
